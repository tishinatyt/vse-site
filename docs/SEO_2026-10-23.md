# SEO и Google Search Console — ВСЕ

Основной адрес: https://tishinatyt.github.io/vse-site/

## Настройки сайта

- Главная страница — статический HTML: содержимое и декларация доступны без JavaScript.
- Канонический адрес и `og:url` указывают на основной адрес с завершающим `/`.
- `robots` главной: `index, follow, max-image-preview:large`.
- Open Graph и Twitter Card используют существующую иллюстрацию `hero.jpeg` (1536 × 1024).
- JSON-LD связывает Organization, WebSite, WebPage и декларацию CreativeWork. Названия, описание, логотип и Telegram-канал взяты с существующей страницы.
- `sitemap.xml` содержит только главную. Разделы с `#` — части одной страницы, отдельными URL карты сайта не являются.
- Служебный `brief.html` имеет `noindex, follow` и исключён из sitemap. Это ограничение индексации, а не доступа к странице.
- Предварительная загрузка фоновой иллюстрации и соединение с сервером шрифтов добавлены без изменения оформления.

## Подключение Search Console

1. В https://search.google.com/search-console/welcome добавить **ресурс с префиксом URL**: `https://tishinatyt.github.io/vse-site/`.
2. Выбрать **HTML-тег**, получить выданный Google `google-site-verification` и поместить его в `<head>` `index.html`. Либо загрузить HTML-файл, выданный Google для этого ресурса, в корень этого репозитория.
3. После публикации проверить точное содержимое тега/файла по публичному адресу, затем нажать «Подтвердить» в Search Console. Не удалять подтверждение после успешной проверки.
4. В разделе «Файлы Sitemap» отправить `sitemap.xml`: https://tishinatyt.github.io/vse-site/sitemap.xml.
5. Проверить главную через «Проверка URL»; запросить индексирование при необходимости.

23 октября пользователь передал HTML-тег для ВСЕ. Точный `google-site-verification` добавлен в `<head>` главной страницы. Проверка владения в аккаунте Google и отправка sitemap ещё не подтверждены: после публикации нужно нажать «Подтвердить» и отправить карту сайта в Search Console. Разметка и наличие sitemap сами по себе не подтверждают владение и не гарантируют индексацию или расширенные результаты.

## Особенность GitHub Pages

Поисковик читает `https://tishinatyt.github.io/robots.txt` в корне хоста. Файл по адресу `/vse-site/robots.txt` не управлял бы обходом этого сайта, поэтому такой файл не создавался. Корень хоста и соседние проекты в рамках этой работы не изменялись. Правила индексации заданы метатегами, а sitemap следует отправить непосредственно в Search Console.

## Проверка изменений

Проверяются валидность XML/JSON-LD, ссылки между узлами Schema.org, единственный canonical и H1, совпадение описаний, наличие локальных ресурсов, `noindex` брифа. Содержимое `<body>`, CSS и исполняемый JavaScript сохраняются без изменений. После публикации требуется проверить ответы HTTP и фактический HTML главной, брифа и sitemap.
